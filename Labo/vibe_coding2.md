Tâches du laboratoire :
Étape facultative : identifiez une tâche pour laquelle une application pourrait apporter une valeur ajoutée
Si ce n'est pas déjà fait, remplissez la 
fiche de travail
 issue d'une lecture précédente. 

Une fois que vous avez identifié une tâche pour laquelle une application pourrait apporter une valeur ajoutée, définissez les données d’entrée de votre application, ce qu’elle fera de ces données et comment elle présentera le résultat. 

Exprimez-le à l’aide de ce modèle : « Mon application reçoit [des données d’entrée] et effectue [un processus] pour créer [un résultat] qui m’aide à [objectif]. »

Si vous avez besoin d’aide, ouvrez un nouvel onglet et accédez à l’application Gemini en saisissant l’URL 
gemini.google.com
. Ensuite, essayez la requête suivante dans Gemini :

I’m a [your role, e.g. social media manager]. I often find myself [task from the worksheet, e.g. drafting posts and creative visuals around holidays]. I want to build an app that makes this easier. It must be simple, standalone, and not dependent on external databases or systems. Suggest 3-5 ideas. Format each using this template: "My app takes {{inputs}} and does {{process}} to create {{output}} that helps me {{goal}}."

Étape 1 : Décrivez l’application que vous souhaitez créer
Dans AI Studio, accédez à l’onglet « Créer ». Collez la requête ci-dessous dans le champ prévu à cet effet et remplacez le texte entre [crochets]. Si vous avez effectué l’étape facultative précédente, utilisez le résultat obtenu ici. 

I want to build an app that takes [inputs] and does [process] to create [output] that helps me [goal].

AI Studio va générer la première version de votre application. La création de l’application peut prendre quelques minutes. Examinez l’application et testez-la avec vos propres données.

Étape 2 : Améliorez votre application
Au cours de la même session de création dans AI Studio, affinez votre application. Vous pouvez coller la requête ci-dessous dans le champ de discussion pour ajouter de nouvelles caractéristiques afin de rendre votre application plus utile ou d’ajuster ses capacités. Remplacez le texte entre [crochets] par vos propres informations.

Add [element, e.g. a button] that [purpose, e.g. copies all the content so I can paste it into a spreadsheet].

Vous pouvez répéter cette étape autant de fois que vous le souhaitez pour ajouter d’autres caractéristiques à votre application. Veillez à fournir des instructions pertinentes à chaque fois.

Étape 3 : Effectuez une modification du style visuel de votre application
Au cours de la même session de création dans AI Studio, collez la requête ci-dessous dans le champ de discussion pour effectuer une modification de l'apparence de l'application. Remplacez le texte entre [crochets] par vos propres informations.

Change the [visual property, e.g. the color scheme] of the app to use [style description, e.g. shades of blue].

Vous pouvez répéter cette étape autant de fois que vous le souhaitez pour donner à l’application l’apparence que vous souhaitez. Fournissez à chaque fois des instructions ou des références pertinentes.

Étape 4 : Partager votre application
Pour partager votre application, cliquez sur le bouton « Partager ». Activez l’option « Publier votre application » pour la rendre accessible à l’URL indiquée sur cet écran. Vous pouvez partager cette URL avec vos collègues afin qu’ils puissent utiliser votre application.

Une fois publiée, votre application est accessible à tous. N’oubliez pas que vous êtes responsable des résultats qu’elle produit et que vous devez être prêt à assurer le bon fonctionnement de l’application pour vos utilisateurs.
